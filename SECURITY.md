# Política de segurança

## Dados que não devem entrar no Git

- senhas ou hashes reutilizáveis;
- arquivos `.pgpass`;
- chaves SSH privadas;
- tokens de acesso;
- dumps com dados pessoais ou corporativos;
- endereços públicos e informações internas desnecessárias.

## Reporte

Ao identificar uma exposição, não abra uma issue pública com o segredo. Revogue ou altere a credencial imediatamente e faça contato privado com o mantenedor.
